      How it works

      1. Add up to 3 videos from your device. They are never uploaded anywhere.
      2. Pick a target size: 16 MB for WhatsApp, 25 MB, 64 MB, or your own number.
      3. Pick a resolution and a quality setting. The page shows the planned video bitrate before you compress anything.
      4. Press Compress. The encoder runs in your browser, one video at a time, and each finished video gets its own download.

      Honest notes

      First run downloads the encoder. FFmpeg.wasm is about 30 MB, fetched from a pinned CDN release on first use and cached by the browser after that. With no connection, compression is unavailable and the page says so — there is no server to fall back to, because the whole point is that nothing uploads.

      Speed depends on your device. Compression runs on one browser thread (the multi-thread core needs special server headers this static site cannot set). A short phone clip finishes in seconds; a long 4K video can take many minutes and use a lot of memory. Keep the tab open while it runs.

      The output is MP4 (H.264 + AAC). MP4 was chosen because WhatsApp, phones and browsers all play it. A WebM/VP9 output would sometimes be smaller but encodes far slower in the browser and plays in fewer places.

      Target size is a target, not a promise. The encoder aims at the bitrate the target implies, but busy scenes and already-compressed sources vary. A finished file can land above or below the target, and the result panel reports the honest numbers — including when the result is larger than the original.

      Very large files can run out of memory. The whole video is held in browser memory during encoding. If a multi-gigabyte file fails, split it into shorter clips first, or lower the resolution.

      Codec support varies by browser. MP4 and WebM cover nearly everything, but whether a particular video decodes depends on your browser's codecs, not on ShrinkVid. If a file loads but shows no picture, try another browser or re-export it as MP4.

      Output filenames keep your original name with "-compressed" added, so the original is never overwritten.
